# CV

A single-page personal CV/resume site. Plain HTML, CSS and JavaScript — no build step, no dependencies.

## Personalize

Open `index.html` — there's a checklist comment at the top listing every spot to edit
(name, title, bio, experience, skills, projects, education, contact links, résumé link).
Editable text is also marked inline with `<!-- EDIT: ... -->` comments.

Replace `assets/avatar.svg` with a real photo (update the `<img>` tag's `src`/`alt` in
`index.html` if you switch to a `.jpg`/`.png`).

## Run locally

Just open `index.html` in a browser — no server required.

## Deploy

Any static host works (GitHub Pages, Netlify, Vercel, etc.). For GitHub Pages: push to
a repo and enable Pages for the `main` branch, root folder — `index.html` is already at
the repo root.
